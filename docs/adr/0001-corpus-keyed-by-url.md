# 语料库以 URL 去重，TTL 30 天，不设硬上限

本地语料库按规范化 URL 作唯一键，重新遇到同一 URL 时更新其内容与向量；条目存活 30 天后过期，不设条数硬上限。选 URL 而非内容 hash，是因为同一 URL 在不同查询/引擎下的摘要文本不同，内容 hash 会导致召回命中率趋近于零；选纯 TTL 而非硬上限，是为了先保持轻量。

## Considered Options

- **内容 hash 去重**：语义最精确，但同一页面反复入库、跨查询命中率近零，被否。
- **条数硬上限**：更安全，但需要额外的 LRU/LFU 逻辑，先不做。

## Consequences

- 页面改版后仍可能按旧向量召回，由 30 天 TTL 限制其存活。
- 突发流量下语料规模 = 日新增 × 30 天，理论上可能写满磁盘。
