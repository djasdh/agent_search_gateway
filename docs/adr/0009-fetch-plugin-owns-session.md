# 取件插件自管会话与请求，网关无条件信任

取件插件自己管理凭据、会话与重定向（含逐跳），网关**不**向它传递也不会干预其 headers/cookies；插件的匹配规则与状态由插件自定，网关**无条件信任**。这样网关核心保持无状态，跨请求状态全部下沉到组件（searxng 引擎、取件插件）内部，由组件各自负责清理。代价是安全边界落在插件作者身上：SSRF、大小上限、超时、落盘路径目前**无网关层兜底**（`TODO.md` 记 `TODO(取件插件安全)`）。

## Considered Options

- **网关持有会话并按 host 注入（穿透重定向链）**：要把 cookies 一路穿过通用重定向循环，状态与特例进入核心路径；被否。
- **插件状态由网关托管（生命周期 / 清理）**：把"每个站点的会话什么样"做成网关的通用能力，过度设计；被否。
