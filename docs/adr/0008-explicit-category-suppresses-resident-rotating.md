# 指定非通用类别时，抑制常驻源与轮换源

当请求显式指定了 `general` 以外的类别（如 `science`）时，网关不再叠加常驻源与轮换源，`engines` 参数留空、交由 searxng 按类别选引擎；`categories=general` 或未指定类别时维持原行为（常驻 ∪ 轮换）。理由是常驻源与轮换源本身就是**通用类**来源，显式选了别的类别即表示"只要这一类"。

## Consequences

- `categories` 从"与 `engines` 并联的过滤项"变成"可排他的选择"——两者语义不再对称。
- 显式 `general` 与"未指定"在行为上等价；这一档反直觉，本 ADR 即为解释。
